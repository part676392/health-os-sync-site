プライバシーポリシー

最終更新: 2026年11月13日

Health OS Sync（以下「本ツール」）は、利用者本人（以下「利用者」）の Google アカウントから健康・フィットネスに関するデータを読み取り、利用者本人の健康記録として保存する個人用ツールです。本ポリシーは、本ツールが取得する情報とその取り扱いを説明します。

1. 取得する情報

  • 睡眠に関する情報（睡眠時間、睡眠段階）
  • 活動に関する情報（歩数、活動エネルギー、距離、運動セッション）
  • 健康指標（心拍数、安静時心拍、心拍変動、血中酸素飽和度、呼吸数）
  • 身体測定値（体重、体脂肪率など）
  • プロフィール情報（年齢層、性別などの基本情報）

本ツールは Google Health API の読み取り専用スコープのみを使用し、Google 側のデータを書き換えることはありません。

2. 利用目的

取得した情報は、利用者本人の健康記録の作成・表示・傾向の確認という目的にのみ利用します。それ以外の目的には利用しません。

3. 保存場所と安全管理

取得した情報は、利用者が管理するサーバーに保存されます。通信は HTTPS で暗号化され、アクセスには利用者本人が発行したトークンが必要です。保存先へのアクセスは利用者本人に限定されます。

4. 第三者提供

取得した情報を第三者へ販売、貸与、提供することはありません。広告配信、信用調査、保険引受の目的で利用することもありません。

5. Google API サービス ユーザーデータ ポリシーへの準拠

本ツールによる Google API から取得した情報の利用は、Google API サービス ユーザーデータ ポリシー（限定使用の要件を含む）に準拠します。取得した情報は、本ポリシーに記載した目的の提供に必要な範囲でのみ利用し、転送・販売は行いません。

6. 保存期間と削除

取得した情報は、利用者本人が削除するまで保存されます。利用者は、Google アカウントの「サードパーティ アプリとサービス」から本ツールのアクセス権を取り消すことができ、取り消し後は新たな取得は行われません。保存済みの記録は、利用者本人がサーバー上のデータを削除することで消去できます。
